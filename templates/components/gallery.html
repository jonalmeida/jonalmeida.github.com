{# An image gallery viewer that can render selected images from a provided `files` list, a `dir` directory, or otherwise all images in the `page.assets` if no arguments provided. Components are hygienic, so `page` must always be passed in. Examples: # Renders all images that can be found. {{ }} # Renders all images in the sub-directory `top_images`. {{ }} # Renders all images listed in the `files` parameter. {{ }} The markup is emitted on a single line: a blank line or an indented line would end the HTML block and hand the rest to the markdown parser. #} {% component gallery(page: map, files: array = [], dir: string = "") -%} {%- if files -%} {%- set assets = [page.colocated_path ~ file for file in files] -%} {%- elif dir -%} {%- set assets = [asset for asset in page.assets if dir in asset] -%} {%- else -%} {%- set assets = page.assets -%} {%- endif -%}
{%- for asset in assets -%} {%- if asset is matching(pat="[.](jpg|png)$") -%} {%- set image = resize_image(path=asset, width=240, height=180) -%} {# When pages that have a date prefix location, get_url does not get the generated path to an asset, so we have to make our own. The original documented way to get the asset path: `` See: getzola/zola/issues/788 #} {%- set asset_name = (asset | split(pat="/"))[-1] -%} {%- endif -%} {%- endfor -%}
{%- endcomponent gallery %}
